# Data Analytics Projects

This folder contains projects focused on **data analysis, business intelligence, and data visualization**.

The goal of these projects is to extract insights from data, answer business questions, and present results through dashboards and reports.

## Tools Used

- SQL
- Python
- Pandas
- NumPy
- Tableau
- Excel
- Matplotlib
- Seaborn

## Projects Included

### Bike Stores SQL
SQL analysis of a retail database to answer key business questions related to sales performance, customers, and product trends.

### Retail Data Project
Exploratory data analysis of retail data to identify patterns, trends, and opportunities for business decision-making.

### Superstore World Project
Interactive dashboard built in Tableau to analyze sales, profits, and regional performance.

### USA House Prices Project
Data analysis and visualization of housing prices across the United States.

### Walmart Project
Retail data analysis exploring store performance, customer purchasing behavior, and sales patterns.

## Skills Demonstrated

- SQL querying
- Data cleaning and transformation
- Exploratory data analysis
- Business data interpretation
- Data visualization and dashboards
