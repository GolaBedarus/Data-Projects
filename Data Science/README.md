# Data Science Projects

This folder contains projects focused on **machine learning, predictive modeling, statistical analysis, and advanced data analysis**.

These projects demonstrate the use of data science techniques to build models, extract patterns from data, and generate predictive insights.

## Tools & Libraries

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow
- PyTorch
- Matplotlib
- Seaborn

## Machine Learning Techniques

- Supervised Learning
- Unsupervised Learning
- Regression Models
- Classification Models
- Model Evaluation
- Feature Engineering
- Cross Validation
- Hyperparameter Tuning
- Deep Learning
- Time Series Analysis
- Natural Language Processing (NLP)

## Projects Included

### Financial Fraud
Machine learning models to detect fraudulent financial transactions.

### Insurance Claims
Analysis and modeling of insurance claim data to identify risk patterns.

### Regresion Lineal Salario
Regression model predicting salary based on experience and other variables.

### Sentiment Analysis
Natural language processing project analyzing sentiment in text data.

### Simulación de Montecarlo
Probabilistic modeling using Monte Carlo simulations.

### US Accidents
Exploratory data analysis and modeling of traffic accident data in the United States.

### Vehicle Insurance Claim Fraud Detection
Machine learning models applied to detect fraudulent vehicle insurance claims.

### Wine Quality
Predictive modeling to determine wine quality based on physicochemical features.
